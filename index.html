§4 Research

2025 – 2026

TestCouncil: multi-agent LLM unit-test generation · BSc thesis, Software Quality Research Lab, Sharif

Qwen, DeepSeek and Gemini write tests for the same function in parallel; an LLM synthesis step merges them and removes about 85% of the tests as redundant. The finding I did not expect: giving the models personas made no significant difference. Using different models did.

2025 – 2026

LLM issue-title generation · Intelligent Software Engineering Lab, Sharif

A learned selection step decides which parts of a GitHub issue an LLM actually needs in order to write a good title: 37.3% fewer input tokens, within 0.004 BERTScore of the GPT-4 baseline, on a dataset of 2.6M+ issues. Supervisor: Prof. Abbas Heydarnoori.

§5 Open source

Envoy · Lua · Istio

local-rate-limit

Per-user, per-API rate limiting at the proxy, so no service has to implement it. A small Lua filter works out who is calling; Envoy's token buckets do the rest. A clean re-implementation of the pattern I first built at Tapsi, with integration tests against a real Envoy.

Python · no LLM needed

grad-tracker

Every UK graduate role in one list, ranked against your CV, running on your own laptop. I replaced its first LLM scorer with a few hundred lines of rules: rank correlation 0.83 with the LLM's scores on a 290-role benchmark, in under a second, for nothing. Public release soon.

Python · LLMs

automatic-paper-critique

Four LLMs critique a paper and rank each other's points in shuffled order, to cancel position bias. A Borda count merges the rankings into one review.

All repositories, including a C-Minus compiler front end and a venue-booking platform on Spring Boot and Kafka.
