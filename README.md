# sepehrvahedi.github.io

Personal site of **Sepehr Vahedi**, software engineer (backend, distributed systems, ML infrastructure), MSc @ UCL.

Live: https://sepehrvahedi.github.io

- Hand-written HTML, CSS and vanilla JS. No frameworks, no build step.
- Interactive terminal in the hero (`help`, `projects`, `cv`, `contact`, `sudo hire-me` …).
- Dark and light themes, responsive down to phone width, respects `prefers-reduced-motion`.
- CVs: [`assets/CV_Sepehr_Vahedi.pdf`](assets/CV_Sepehr_Vahedi.pdf) (backend) and [`assets/CV_Sepehr_Vahedi_ML.pdf`](assets/CV_Sepehr_Vahedi_ML.pdf) (ML platform).

Run locally: `python3 -m http.server` and open http://localhost:8000.
